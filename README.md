# LightData

Android 和网页版单屏取景器与胶片测光表。安卓版最低支持 Android 9，使用 Camera2 采集图像、Compose 排布控件、OpenGL ES 绘制预览。应用在本机处理图像，退出拼接或测光点模式后即可回到实时画面。

## 安卓广角拼接

确认中心后缓慢扫向覆盖图的黄圈。Android 使用 OpenCV 4.12 的角点检测、双向金字塔光流和 RANSAC 相似变换配准移动关键帧。采集时会在支持的镜头上锁定自动曝光和白平衡，按相邻帧重叠区域估算剩余色差，并在线性光域融合边缘。低照度或画面缺少纹理时，放慢转动或短暂停住可帮助补拍。已采集区域外的黑色空白继续排除在测光之外。

## 网页版

[打开 LightData Web](https://rayforloy.github.io/LightData/) · [Android 安装包](https://github.com/RayforLoy/LightData/releases/tag/0.2.0-beta)

网页版使用原生 JavaScript、Canvas 和按需加载的 OpenCV.js，静态文件位于 `web/`，无需服务器处理相机画面。沿用安卓版的单屏布局、横竖屏及近方形折叠屏排布，支持拖动分界线、A/S/M、±5 EV 补偿、多列等效曝光和倒易律时间、168 款胶片、ISO 锁定、JSON 预设、胶片预览、不同颜色的冻结测光点及直方图平移缩放。手机图像和设置均在本地处理、保存，不上传相机画面。手册仍为外部链接，页面仅加载提取后的曲线和来源。

首次访问或切换到未配置过的相机时弹出镜头设置。可在弹窗里开启预览、选择浏览器相机，再输入手机采集光圈与水平视角，或用厂家给出的 35 mm 等效焦距估算视角。切回已配置的镜头会恢复参数；设置中可随时重新配置。目标镜头光圈在测光表中另行设置。取景随视频帧更新，测光单独采样。同一视频轨道的 `getSettings()` 每 500 ms 重新读取一次，无需反复申请相机。

网页支持简体中文和英文，首次按浏览器首选语言选择，也可在设置的 Language / 语言中切换并记住选择。工具栏、镜头配置、测光状态、直方图、胶片资料、LUT 条件和错误提示均提供英文；切换语言保留镜头参数与测光设置。设置中的“设置当前镜头的视角与光圈”按钮使用琥珀色高亮。

直方图像素纵轴默认使用对数。旧版保存的纵轴设置首次升级时切换到对数，此后记住手动切换的线性或对数选择。设置底部的“重置设置”恢复默认取景、测光、显示和布局并刷新页面，保留镜头光圈与视角、响应校准记录及自定义胶片预设。

[手机镜头参数库](web/data/cameras.json)目前收录 283 个型号、810 条后摄参数，覆盖 Samsung、Apple、HUAWEI、HONOR、Xiaomi、OPPO、vivo。Apple 包含 iPhone X 起全部 38 款，各代 mini、Plus、Pro Max、SE 和其他分支独立选择；其余品牌为 2022 年起在中国大陆发布、至少一种首发配置 MSRP 严格超过 4000 元的机型，原有历史支持保留。631 条具有有来源的等效焦距或明确视角，剩余条目保留光圈并提示手动填写范围。手机按品牌、型号两个联动下拉框选择。规格、原评测焦距与首发价格分别保留来源，详见[覆盖范围与分品牌资料](docs/phone-catalog.md)。优先通过 [UA Client Hints](https://developer.chrome.com/docs/privacy-security/user-agent-client-hints) 读取型号，未开放时尝试 User-Agent；全部在本地匹配。简化 UA、共享型号代码或镜头名称存在歧义时要求手选，不根据相机编号猜测物理镜头。

- 默认自动使用浏览器返回的有效快门与 ISO，只需手填手机采集光圈，即可持续计算场景 EV100、直方图和目标曝光组合。设置中的快门、ISO 自动显示当前读取值，参数每 500 ms 刷新；缺少参数时清空旧值并显示相对亮度。自动曝光读数标为可能滞后的估测；可选择“仅使用已固定的曝光参数”，或实际固定曝光后手填参数、使用已知 EV 标定。参考标定在采集参数改变后失效，重开相机需重新确认曝光。快门按 [Media Capture 标准](https://w3c.github.io/mediacapture-image/#dfn-exposure-time)的 100 微秒单位换算，支持小数值。
- 浏览器通常不提供可靠的镜头视角。可输入当前预览的水平视角、35 mm 等效焦距，或以已知距离和覆盖宽度标定。等效焦距按 35 mm 画幅对角线换算至原生 4:3 画面，再按当前预览比例中心裁切并计入缩放，属于估算；电子防抖和厂家额外裁切需用实测水平视角修正。方向未注明的厂家 FOV 只展示资料，不当作水平或对角角度自动填入。光学参数按浏览器镜头保存，旋转或缩放时换算，响应校准仍按预览配置与 ISO 单独保存。目标超出覆盖范围时显示拼接入口，缺失区域保留斜纹空白。拼接采集目标宽高各 115%，结合可用的设备姿态和重叠图像配准，完成后可转动设备或拖动画面二次构图。覆盖图提示补拍。无姿态权限时使用画面配准引导。单帧纹理、运动及浏览器相机处理会影响配准。
- 校准支持灰卡、九级阶梯卡和现场预览估测。浏览器开放手动快门时可自动扫描，否则需实际改变采集曝光并输入各档参数；至少 5 档、跨越 4 EV，每档采两帧。仅修改输入框不能校准。结果按当前镜头预览配置和采集 ISO 保存，失败保留旧记录；不把浏览器处理后图像标为 RAW 校准。
- 「更多」提供滤镜与皮腔补偿、逐镜头毛玻璃校准和同点实测光损、构图快照与叠影、水平尺和测光确认音。冻结后点击编号测光点可指定 Zone。光损同时影响推荐曝光和预览的有效中灰位置，倒易律只调整建议的实拍时长。倒易律按胶片型号匹配，优先用手册，再显示带来源和外推说明的网络估算。

请从 HTTPS 页面访问，允许相机；支持姿态的设备还需允许运动传感器。可访问的镜头、手动曝光与运动传感器由设备和浏览器决定。尚未进行网页真机精度验收，验证范围见 [网页版测试记录](WEB-TEST.md)。

网页拼接会在后台线程用 OpenCV 角点、双向光流和 RANSAC 配准清晰的移动关键帧。有足够匹配点时会用未参与拟合的点复验，接缝采用局部残差网格和分区线性 RGB 增益修正。浏览器开放手动控制时，尝试在等效曝光下把采集快门推近 1/100 秒，并在回读确认后保持曝光与白平衡。退出拼接时恢复原模式。覆盖图用十字标记起点，用白圈显示当前方向，用黄圈建议补拍。快门较慢、未知或画面匹配困难时可放慢转动或短暂停稳。OpenCV 仅在开始拼接时从本站加载，发行文件、许可证与 SHA256 见 [vendor 记录](web/vendor/README.md)。

## 使用

- 点击取景器顶部的画幅和焦距，输入目标相机的数据。自动选镜会在手机开放的后置摄像头中选择能够覆盖目标视场的镜头。缺失视场显示为暗区，确认中心后按覆盖图转动手机，采满 115% 范围后即可小幅转动手机二次构图。
- 测光表的每一列是一组快门和光圈。列间保持同一 ISO 下的等效曝光，琥珀色标出当前组合。点击其他列可选用该组。A、S 档可在档位下方以 1/3 EV 步进拨动 −5 至 +5 EV 的补偿，正值增加胶片曝光。M 档显示手动设置的曝光偏差。横拖可微调 A 档光圈或 S 档快门。M 档分别拖动快门区和光圈区，改变曝光偏差。ISO 刻度独立调节，设置里可输入自定义数值。
- 点“连续”跟随场景，点“单次”采样并保持读数，再点“单次”重新测量。工具栏的测光点会冻结画面，在取景器中点按添加编号并标到直方图，重复点按同一位置可移除。直方图横轴表示场景的绝对 EV100，Zone V 位于当前目标曝光组合对应的 EV100。相机和胶片的设置变化会移动分区和曝光界限。横拖平移，双指水平或垂直拉开可分别放大两轴。红色斜线为过曝，绿色反向斜线为欠曝。
- 在设置里选择胶片及色彩映射，用工具栏“预览”切换胶片响应。在 HP5 PLUS 的长曝光列中，箭头指向实拍时间。PORTRA 400 和 E100 按各自厂家的适用范围提示。胶片外观、用户自定义的响应和厂家数据在设置中分别说明。[ILFORD 倒易律补偿指南](https://www.ilfordphoto.com/wp/wp-content/uploads/2024/05/Reciprocity-Failure-Compensation-v2.pdf)
- “组件比例”会显示可拖动的分隔线，工具栏点“完成”保存。竖屏与横屏独立记忆。

- 设置中的“直方图像素纵轴”可在线性与对数之间切换。对数模式用 log(1 + 像素数) 显示少量像素，右侧胶片密度 D 仍按原刻度显示。测光点与其直方图竖线按编号配色。
- 近方形大窗口（短边至少 540 dp，长短边比不超过 1.30）竖屏时左侧取景、右侧上下排列两块仪表；横屏时上方取景、下方左右排列仪表。两种内屏布局与普通屏幕分别保存分隔线位置。

## 胶片 LUT 预览

184 张 LUT 覆盖 122 款胶片，包括 80 种上游配置组合和 104 个派生配置。[查看建模依据与误差](web/luts/README.md)

在设置中将预览按钮切换为「LUT」，选择胶片及可用的冲印或观看方式，再点工具栏的预览按钮。反转片可以预览 D50 灯箱下的透射颜色。负片可选择对应的相纸或电影拷贝片。型号和工艺来自上游或手册派生时，设置会显示来源类别。没有适用 LUT 的胶片和自定义预设使用原有亮度模拟。

LUT 只作用于显示。每个像素仍按相机响应和当前曝光设置定位到胶片曲线，中性灰的亮度由该片的正像曲线决定。彩色区域额外应用 LUT 对该颜色的响应，同时约束在相应的阴影、中间调或高光范围。直方图、点测光和红绿警示都使用显示变换前的曝光值。手册曲线给出的界限取决于显影条件、图上可读范围和中灰锚点；现场的光谱和实际冲洗也会影响成像。

实时渲染倍率可选 25%、50%、75% 或 100%，百分比作用于两个像素维度。画面稳定或冻结测光点时恢复当前取景源的完整可用分辨率。倍率只改变预览绘制，测光采样保持独立。两端共用同一套 33³ 查找表。网页版按所选型号加载，安卓包支持离线使用。[Spektrafilm 源项目](https://github.com/andreavolpato/spektrafilm)

设置中的帧率显示默认关闭，安卓端为「显示实际预览 FPS」，网页端为「显示取景帧率」。打开后，取景器右上角显示实际更新的帧率。运动时可降低实时渲染倍率减轻计算量，稳定或冻结后恢复完整取景分辨率。取景帧率受相机输出和设备性能影响。

负片按所选曲线在中灰附近的密度梯度确定正像显示反差，亮部平滑收拢。亮度和 LUT 预览共用这个中灰锚点。以 PRO 160S 为例，中性目标处于 −2、0、+2 EV 时，8 位 sRGB 预览灰阶约为 56、118、195。横轴 EV、直方图计数和欠曝/过曝阈值仍由相机和胶片曝光数据计算。

## 胶片 ISO 与自定义预设

在设置的“曝光曲线”中选片时，每个型号旁会显示标称 ISO。选片后测光自动采用并锁定这个 ISO。轻点 ISO 滚轮上的“解锁”即可按自己的曝光指数测光；点“锁定至”恢复标称值。解锁状态和手动值会跨重启保存，下一次选片会重新跟随该片。由旧版升级时，已保存的不同曝光指数保留为手动状态。

“新建预设”可保存胶片或数码型号的名称、标称 ISO、总动态范围和中灰以上的档数。创建后可在“曝光曲线 → 自定义预设”切换，选用时可编辑。用“导出 JSON”备份全部自定义预设，用“导入 JSON”从系统文件选择器读回。文件为 UTF-8 明文；以 UUID 识别预设，同一 ID 更新，其他 ID 追加。导入失败时保留原有预设。

## 测光与胶片曲线对齐

直方图横轴为场景 EV100。选定的快门、光圈和 ISO 决定 Zone V 的位置，胶片曲线 CSV 中的 0 EV 就放在该处。不同型号的中灰锚点依据见设置中的曲线说明。零补偿的 A/S 档尽量把取景框内的平均亮度放在 Zone V，精度受相机档位取整和可选范围影响。测光采用线性亮度求平均，先把两端各 2% 的亮度限制在相应分位数。高反差画面中，亮部会抬高平均读数，使主体落在 Zone V 左侧。点测光可查看主体分区；增加曝光补偿会使主体在胶片曲线上向右移动。

## 校准与资料

灰卡需均匀照明并填满画面；九级阶梯卡需水平排列，按提示输入级差；现场估测需静止且同时含有阴影和高光。每档曝光采两次，用实际快门和 ISO 计算响应，检查移动、噪声和饱和。可取得有效 RAW 时记录 RAW 动态范围，同时校准实时 YUV 预览的响应。其余成功结果标记为 YUV。估测失败会保留原有记录。测光和胶片映射均为现场参考，手机单帧已剪切的亮暗细节无法恢复。

内置 168 款胶片，其中 122 款采用厂家图采样 CSV，46 款明确标记为乳剂类别近似。手册通过设置中的外链查看。50 款提供倒易律依据。CSV 位于 app/src/main/resources/studio/lightdata，包含来源文献 ID、页码、通道、处理条件和中灰对齐方法。密度上下限为图示范围内的预览估算。[银盐图书馆](https://github.com/fuduji000-netizen/silvergrain-library)

## 构建和验证

安装 Android SDK Platform 37 和 Build Tools 36.0.0，配置 Android SDK 路径，并使用 Android Studio 附带的 JDK。Windows PowerShell 命令如下。

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

应用包名为 `studio.lightdata`。调试包输出到 `app/build/outputs/apk/debug/app-debug.apk`。连接 Android 设备后运行 `.\gradlew.bat connectedDebugAndroidTest` 可验证逐镜头校准档案的写入、加载及隔离。

曝光密度数据已合并去重。彩色图的绿层或注明的三层均值用于亮度测光。额外分层数据覆盖 EKTAR 100、PORTRA 160、PORTRA 800，光谱感光度覆盖上述三款及 ULTRAMAX 400。光谱 CSV 保留 nm、log reciprocal exposure 和测量条件，密度 CSV 保留每层的相对中灰 EV 和密度。可通过 tools/digitize_kodak.py 从原手册重建这些数据。

分层预览将手机线性 RGB 以三个高斯可见光基函数近似重建，再按厂家感光谱积分，各层采用中性日光归一化，最后应用对应曝光密度与正像显示变换。手机 RGB 无法确定场景真实光谱，光源变化、同色异谱、红外和冲洗扫描差异会影响色彩。缺少可靠分层数据的型号继续使用其亮度曲线和所选配色。数据表中的 122 款采样并不代表 356 份资料都含可辨识曲线，历史版本与多型号手册在统计中分别处理。
[胶片数据核验记录](FILM-DATA.md)列出厂家原图、光谱测量条件、重复曲线及倒易律公式的适用范围。
